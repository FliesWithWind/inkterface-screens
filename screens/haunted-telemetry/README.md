# Haunted Telemetry

A Halloween telemetry screen: the usual live numbers, haunted. A jack-o'-lantern sits between two
columns of readings, bats flap beside the clock, cobwebs hang in all four corners, and the footer
wishes you a Happy Halloween.

## What it shows

- Clock and date, under a "witching hour" subtitle
- CPU: "SOULS CONSUMED" (load, number plus a thin bar) and "CRYPT FEVER" (temperature)
- GPU: "GHOSTS SUMMONED" (load, number plus a thin bar) and "HELLFIRE" (temperature)
- "NOW HAUNTING": the game you are playing and how many minutes the session has run
- Original art, drawn for this screen: bats, jack-o'-lantern, cobwebs

## Built for fast partial refresh

Only the readings change: the clock, four numbers, two thin bars, the game name and the session
minutes. Each sits in its own small fixed box, none overlaps another widget, and none sits on a
black fill, so the panel only has to repaint those boxes. Everything else is static.

## Settings

None.

## Data it needs

- `time.now`
- `system.cpu.load`, `system.cpu.temp`, `system.gpu.load`, `system.gpu.temp`
- `steam.now_playing.name`, `steam.now_playing.session_minutes`

Missing values render as `--`, and with no game running the "NOW HAUNTING" line shows `--`.

## Notes

The format has no date arithmetic, so there is no live countdown to October 31; the footer is a
fixed greeting. The artwork in `assets/` is generated by `tools/make_haunted_art.py` (Pillow
primitives, no third-party images).
